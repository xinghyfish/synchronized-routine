# LLM 为什么不是数据库或者搜索引擎

从本质上来看，LLM是一种概率预测函数，通过上下文对输出token的概率进行计算，并采样输出成字符。LLM 本质上是一种概率拟合，存储的是**参数**而非真实的**数据**，每次输出的结果都是不稳定的。

数据库则是一种数据组织和查询工具，将数据以某种格式存储在磁盘中，通过结构化查询语句进行数据的增删改查。在表结构和数据不比你的情况下，同一个SQL的查询结果是稳定的。本质上是基于某种固定规则的函数映射而非概率采样。

搜索引擎类似于数据库，不过搜索引擎内置了更多文字处理、排序的算法，用于将用户希望检索的信息以更高的优先级进行展示，而不是仅仅实现准确性。

综上，不能将LLM 用于数据的检索，因为所有 LLM 生成的内容都是通过参数构建的概率模型所产生的，结果是不稳定的、甚至可能出现幻觉。在对结果准确性有一定要求的环境中，一定要添加一定的后置步骤用于对LLM的输出进行校验。
